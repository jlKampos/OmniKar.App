Privacidade

Os teus dados são teus. Sempre.

1

Onde ficam os teus dados

O OmniKar guarda os dados em dois locais — nenhum deles é um servidor externo gerido pelo desenvolvedor:

  • No teu dispositivo — todos os dados da app (viaturas, manutenções, combustível, inspeções, seguros, impostos, pneus, donos, agendamentos) são guardados numa base de dados SQLite local. Só tu, com o teu telemóvel, tens acesso.
  • No teu Google Drive pessoal — quando fazes login com a tua conta Google, o OmniKar guarda uma cópia de segurança (backup) e as localizações GPS na pasta privada da app (appDataFolder) do teu próprio Drive. Esta pasta é invisível na interface normal do Google Drive — só a própria app OmniKar (com a tua conta) lhe acede.
2

Sem servidores externos

O OmniKar não usa servidores externos. Não há uma base de dados na cloud gerida por mim. Não há logs de utilização, análises de tracking ou partilha de dados com terceiros.

O único acesso remoto que a app faz é à tua própria conta Google Drive — e apenas à pasta privada da app (drive.appdata).

Eu, como desenvolvedor, não tenho acesso aos teus dados. Não os vejo, não os recolho e não faço gestão dos mesmos. Tu és o único proprietário e responsável pelos teus dados.

3

Não visível no Google Drive

Os ficheiros do OmniKar na nuvem estão na pasta privada da app (appDataFolder). Esta pasta:

  • Não aparece quando abres o Google Drive no browser ou na app
  • Só é acedida pela app OmniKar com a tua conta Google
  • Não conta para o espaço de armazenamento do teu Drive
4

Como apagar os teus dados

☁️ Apagar os dados da nuvem

Vai às Definições → Nuvem → "Apagar dados da nuvem". Isto remove tudo o que está no Google Drive:

  • O ficheiro de backup completo
  • Todas as localizações GPS de todas as viaturas

Nada fica para trás. Esta ação não pode ser desfeita.

📱 Apagar os dados do dispositivo

Para remover os dados locais (app), desinstala o OmniKar do teu dispositivo Android. Isto apaga a base de dados SQLite e todos os ficheiros da app no telemóvel.

⚠️ Importante: apagar a nuvem não apaga os dados locais (viaturas, manutenções, etc.). Desinstalar a app não apaga os dados que estão no Google Drive. Se quiseres remover tudo, faz as duas ações: apaga da nuvem pela app e depois desinstala.
5

Resumo

O OmniKar foi construído com o princípio de que os teus dados são teus:

  • ✅ Sem servidores externos — tudo no teu dispositivo ou no teu Google Drive
  • ✅ Sem anúncios — a app não recolhe nem partilha dados para publicidade
  • ✅ Sem tracking — a app não monitoriza o teu comportamento nem envia análises
  • ✅ Tu controlas — podes apagar os teus dados a qualquer momento
  • ✅ O desenvolvedor não vê nem gere os teus dados
